# 📈 StockTracer Pro

StockTracer Pro is a real-time stock market tracking web application built with **React**, **Vite**, **Tailwind CSS**, and **Recharts**. It allows users to view the latest stock prices, price changes, and live charts of trending stocks with a dark/light theme toggle.

🚀 **[Live Demo](https://stocktracerpro.netlify.app/)**

---

## 🧩 Features

- 🔄 **Real-time stock data** using the [Finnhub API](https://finnhub.io/)
- 🌗 **Dark/Light theme** toggle for better user experience
- 📊 **Interactive line chart** with Recharts
- 🔍 Track multiple stock symbols (e.g., AAPL, GOOGL, NVDA)
- ⚡ Fast and responsive UI with **Vite** and **Tailwind CSS**
- 🎯 Automatic data refresh with controlled API usage to stay within rate limits

---

## 🛠 Tech Stack

- **React**
- **Vite**

- **Axios**

# 🔐 Rate Limits Notice
This app uses the free plan of the Finnhub API which limits API requests to 60 calls/minute. Requests are throttled to avoid 403 errors.
